ADAPTER REQUIRED

Beat Saber

The Loader can detect and launch an installed copy of Beat Saber. Patching, native mod loading and injection require a game-specific adapter and are not implemented in this build.

No Beat Saber version is currently declared compatible. Installing the companion APKs does not patch the game or root a headset.
